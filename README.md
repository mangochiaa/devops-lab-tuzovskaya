# DevOps Lab — Тузовская Арина

Репозиторий создан в рамках лабораторной работы №0 по курсу «Введение в веб технологии».

## О проекте

Это учебный проект для изучения DevOps-практик: работа с Git, ветками, Pull Request'ами и настройкой рабочего окружения.

## План изучения DevOps

1. Основы работы с Git и GitHub (ветки, коммиты, PR).
2. CI/CD — непрерывная интеграция и доставка.
3. Контейнеризация (Docker).
4. Оркестрация (Kubernetes).
5. Инфраструктура как код (Terraform, Ansible).
6. Мониторинг и логирование (Prometheus, Grafana).
7. Облачные платформы (Google Cloud, AWS, Yandex Cloud).
