# Правила участия в проекте (Contributing)

Спасибо за интерес к проекту! Пожалуйста, следуйте этим правилам при внесении изменений.

## Как внести изменения

1. Создайте отдельную ветку для задачи:
   git checkout -b feature/название-задачи
2. Внесите изменения и закоммитьте их:
   git commit -m "Краткое описание изменений"
3. Отправьте ветку на GitHub:
   git push origin feature/название-задачи
4. Создайте Pull Request в ветку main.

## Стиль коммитов

- Используйте осмысленные сообщения коммитов.
- Один коммит — одна задача.
- Примеры: Add README.md, Fix typo in docs, Update dependencies.

## Ветки

- main — стабильная версия проекта.
- develop — ветка для разработки.
- feature/* — ветки для отдельных задач.

## Код-ревью

Все изменения проходят ревью перед влитием в main.
